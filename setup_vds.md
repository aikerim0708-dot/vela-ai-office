# Поднять VDS для VELA — 30-60 минут

После этого агенты работают 24/7 даже когда твой mac выключен.

---

## Шаг 1. Выбор провайдера (5 мин)

| Провайдер | Карта | Цена/мес | Где | Рекомендация |
|---|---|---|---|---|
| **Timeweb Cloud** | МИР работает | 250-350 ₽ | timeweb.cloud | ⭐ для начала, дёшево, понятно |
| Selectel | МИР работает | 350-600 ₽ | selectel.ru | надёжнее, дороже |
| Yandex Cloud | МИР работает | 500-1500 ₽ | cloud.yandex.ru | избыточно дорого |
| Hetzner | Зарубежная карта | €4-6 (~450 ₽) | hetzner.com | дёшево если есть валютная карта |

**Бери Timeweb Cloud** — для VELA сейчас этого хватит.

### Конфигурация которую брать

| Параметр | Минимум | Рекомендую |
|---|---|---|
| CPU | 1 | 2 |
| RAM | 2 GB | 4 GB |
| Диск | 20 GB SSD | 30 GB SSD |
| ОС | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |
| Локация | Москва или СПб | Москва |

Цена такой конфигурации ~250-450 ₽/мес.

## Шаг 2. Регистрация и заказ VDS на Timeweb (10 мин)

1. Открой https://timeweb.cloud/
2. Регистрация через email
3. Личный кабинет → **Облако** → **Создать сервер**
4. Параметры:
   - **Тариф:** Cloud (или "Discovery" если есть — самый дешёвый)
   - **Конфигурация:** 2 CPU, 4 GB RAM, 30 GB NVMe
   - **ОС:** Ubuntu 22.04 LTS (важно — не 24.04, у нас Python 3.9 настроен)
   - **Локация:** Москва
   - **Имя сервера:** `vela-prod` (или любое)
5. **Доступ:** «Создать новый SSH-ключ» → загрузи свой `~/.ssh/id_ed25519.pub`
   - Если делала GitHub-настройку (`docs/setup_github.md`) — этот ключ уже есть
   - Если нет: `cat ~/.ssh/id_ed25519.pub | pbcopy` → вставить
6. Оплати (карта МИР через СБП)

Через 3-5 минут получишь:
- IP сервера (формата `185.xxx.xxx.xxx`)
- Логин: `root`
- Пароль (для аварийного входа) или только по ключу

**Запиши IP** и пришли мне. Дальше я сделаю install-скрипт под него.

---

## Шаг 3. Первая проверка (2 мин)

В Terminal на твоём mac:

```bash
ssh root@<твой_IP>
```

Должно зайти без запроса пароля (через SSH-ключ).

Если ругается «permission denied» — проверь что добавила публичный ключ при создании сервера. Можно добавить через панель Timeweb позже.

Введи `exit` чтобы выйти.

---

## Шаг 4. Запустить install-скрипт (10 мин, я уже подготовил)

После того как у меня будет IP — создам файл `scripts/setup_vds.sh` который делает на VDS:

1. **Базовая безопасность:**
   - Создать пользователя `vela` (не работаем под root)
   - Отключить вход по паролю (только SSH-ключ)
   - Установить `ufw` фаервол, открыть только 22 (SSH) и 443 (HTTPS)
2. **Установка зависимостей:**
   - Python 3.9 (тот же что у тебя локально)
   - nginx
   - Let's Encrypt (для HTTPS)
   - git
3. **Клон проекта** с твоего GitHub (по deploy key)
4. **`.env` с токенами** — переносим вручную, через SSH (не через git)
5. **systemd service** для uvicorn — перезапускается при падении
6. **nginx + Let's Encrypt** — HTTPS на твоём домене (или субдомене Timeweb)
7. **Cron для nightly sync** в GitHub (из урока 3 курса)

Запуск одной командой:
```bash
ssh root@<IP> 'curl -sSL https://raw.githubusercontent.com/aikerim0708/vela-ai-office/main/scripts/setup_vds.sh | bash'
```

## Если что-то пошло не так

| Проблема | Решение |
|---|---|
| `ssh: permission denied` | Проверить что публичный ключ добавлен в Timeweb панели |
| Сервер не отвечает | В панели Timeweb → перезагрузка |
| `curl` не работает | Можно вручную через `apt install curl -y` |
| Нет домена для HTTPS | На первое время — Timeweb даёт тестовый поддомен `vela-prod.tw1.ru` |
